# Ảnh kiểm thử vai trò Agency

Mỗi thư mục là một tính năng; xem bảng kết quả và cách chạy lại ở [`../REPORT.md`](../REPORT.md) §11.

| Thư mục | Nội dung |
|---|---|
| `role-matrix/` | Ma trận 4 vai trò × 23 route + sidebar |
| `owner/` `manager/` `staff/` `accountant/` | Luồng nghiệp vụ của từng vai trò |
| `invitation/` | Mời, chấp nhận lời mời, hai nơi làm việc |
| `isolation/` | Cách ly dữ liệu giữa hai agency |
| `account-states/` | Chưa xác minh, bị khoá, sai mật khẩu, cổng du khách |
| `team-requests/` | Duyệt yêu cầu tham gia |
| `fixes/` | Xác minh F1–F7 sau sửa |
| `commission/` | Xác minh F8 (chiết khấu/hoa hồng) |
| `agency-chat/` | Xác minh F11 (hộp thư chung của agency) |
| `archive/` | 58 ảnh của lượt chạy trước khi sửa (dẫn chứng F1–F11) |
